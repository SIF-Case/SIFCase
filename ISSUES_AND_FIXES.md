**Where the data comes from**:

- **Fields**: `monthKey`, `label`, `summary`
- **Generated by**: `getMonthlyPerformanceData()` function

```typescript

  `A complete look at how Specialized Investment Fund strategies performed in ${data.label},

```

### Stats: "21 funds covered • 2026-05-01 – 2026-05-31 • 6 positive / 15 negative"
**Location**: `src/app/performance/[slug]/page.tsx` (line 62-69)

Computed from:
- `data.funds.length` - total fund count
- `data.rangeStart` and `data.rangeEnd` - from monthKey
- `topGainers` - calculated by filtering positive returns

```typescript
const topGainers = data.funds.filter((f) => f.monthlyReturn >= 0).length;
```

### Data flow:
```
1. PerformanceReport collection (MongoDB)
   ↓ (stores: monthKey, slug, label, summary, published, pdfUrl)
2. getMonthlyPerformanceData(monthKey)
   ↓ (computes from sifnavs collection)
3. Returns MonthlyPerformanceData
   - funds array with returns
   - bestPerformer, worstPerformer
   - avgReturn, positiveCount, negativeCount
   ↓
4. Page renders with computed stats
```

### Function: `getMonthlyPerformanceData()`
**Location**: `src/lib/sifData.ts` (line 965)

**What it does**:
1. Takes a monthKey (e.g., "2026-05") as input
2. Queries all Direct Plan Growth schemes
3. Finds NAV records for that month
4. Calculates monthly returns for each fund
5. Computes statistics (best, worst, average)
6. Returns structured data

**Example data structure**:
```typescript

  label: "May 2026",

  rangeEnd: "2026-05-31",

    // ... more funds
  ],

  positiveCount: 6,
```
